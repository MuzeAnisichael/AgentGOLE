## 3. 公共 API 现状

顶层 `__all__ = ["Agent", "Model", "Result", "Event", "tool", "__version__"]`，版本为 `0.1.0.dev0`。签名中的 `ToolMode` 为 `Literal["auto", "native", "prompt"]`。

```python
class Agent:
    def __init__(
        self,
        model: str | Model | ModelClient | None = None,
        *,
        instructions: str | None = None,
        tools: Iterable[str | Tool] = (),
        memory: str | Memory | None = "session",
        paradigm: str | Paradigm = "auto",
        name: str | None = None,
        max_steps: int = 20,
        timeout: float | None = None,
        tool_mode: ToolMode | None = None,
        verbose: bool = False,
    ) -> None: ...
    def run(self, input: str, *, session: str = "default") -> Result: ...
    async def arun(self, input: str, *, session: str = "default") -> Result: ...
    def stream(
        self, input: str, *, session: str = "default", events: list[str] | None = None
    ) -> Iterator[Event]: ...
    async def astream(
        self, input: str, *, session: str = "default", events: list[str] | None = None
    ) -> AsyncIterator[Event]: ...
    def on(self, event_type: str) -> Callable[[EventCallback], EventCallback]: ...

class Model:
    def __init__(
        self,
        spec: str,
        *,
        base_url: str | None = None,
        api_key: str | None = None,
        temperature: float | None = None,
        max_tokens: int | None = None,
        timeout: float = 60.0,
        retries: int = 2,
        tool_mode: ToolMode = "auto",
    ) -> None: ...
    def generate(self, prompt_or_messages: str | list[Message], **params: Any) -> ModelResponse: ...
    async def agenerate(
        self, prompt_or_messages: str | list[Message], **params: Any
    ) -> ModelResponse: ...
    @property
    def capabilities(self) -> Capabilities: ...

def tool(
    fn: Callable[..., Any] | None = None,
    *,
    name: str | None = None,
    description: str | None = None,
    timeout: float = 30,
    retries: int = 0,
) -> Tool | Callable[[Callable[..., Any]], Tool]: ...

class Result(BaseModel):
    text: str
    steps: list[Step]
    usage: Usage
    trace: Trace
    run_id: str
    session: str
    def __str__(self) -> str: ...

class Trace(BaseModel):
    def show(self) -> None: ...

class Event(BaseModel):
    model_config = ConfigDict(extra="allow")
    type: str
    run_id: str
    ts: float = Field(default_factory=time)
    step: int | None = None

# agentgole.testing
Reply = str | ToolCall | list[ToolCall]
class FakeModel:
    def __init__(
        self, script: Iterable[Reply], *, tools_supported: bool = True, name: str = "fake"
    ): ...
def fake_tool_call(name: str, args: dict[str, Any]) -> ToolCall: ...
```

CLI 入口为 `gole init [--force]`、`gole doctor`、`gole chat [--model M] [path/to/file.py:attr]`。

## 4. 偏差与决策

| 决策 | 原因 | 影响范围 | 需审核确认 |
| --- | --- | --- | --- |
| quickstart 在三行 Agent 用法外增加一条 getenv 导入 | 默认运行指定的 Ollama 模型；A4 可对同一份文件设置 GOLE_MODEL | 示例；README 保留三行写法 | 否 |
| 外部 Tool 使用常见 JSON Schema 约束子集，遇到未支持的断言明确报错 | 保持三个运行时依赖；装饰器参数使用 Pydantic 完整模型校验 | 外部 Tool 的原生和 prompt 校验；支持对象、数组、类型、范围、正则、枚举、本地引用、组合及注释字段 | 否 |
| 输出上限含截断标记；run_end 内嵌结果的轨迹截至前一事件 | 保证 8000 字符总长，避免结果引用自身；run() 的结果保留终止事件 | 工具观察、结果轨迹 | 否 |
| 能力探测计入整次 timeout；取消首次探测后，其他并发 run 可接手 | 探测也是本次运行的 I/O | 共用 Model 的 Agent | 否 |
| doctor 对每个模型用 max_tokens=1 发起真实对话，再读取能力 | 端口通并不能证明指定模型可调用 | doctor 运行时可能产生模型费用 | 否 |
| Windows 的 ZoneInfo 无时区数据时使用系统 ICU | 保持跨平台 IANA 时区支持和三个运行时依赖 | 内置 datetime | 否 |
| Ruff 明确限定 Python 工程文件 | 当前 Ruff 默认格式化 Markdown 代码块；仓库规定 docs/ 只读 | Makefile 与 CI 使用同一条检查命令 | 否 |

## 6. 测试概况

- 离线用例 55 项全部通过；最终 `make check` 用时 8.39 秒。第一次在 Ruff 处理只读 Markdown 时中止，尚未运行 pytest。修正检查范围、类型问题及评审项后完成最终检查。

- live 用例运行一次，共跳过 5 项，原因见第 2 节。无 xfail。
- 未验证的风险包括真实服务端的 SSE 差异、本地模型遵循 prompt 协议的稳定性，以及 GitHub Actions 中的跨系统矩阵；本次执行记录来自本机 Windows。

## 7. 已知问题与技术债

| 问题 | 现象 | 已尝试的方案 | 原因 | 建议 |
| --- | --- | --- | --- | --- |
| live 验收待补 | 本机无法获得两个目标模型的实际回答 | 运行 live 用例一次，手动运行 doctor 一次 | Ollama 端点不可达、缺少 DeepSeek 密钥 | 按第 2 节命令在具备条件的环境验收 |
| 同步 Python 工具超时后的副作用 | 调用方可及时收到超时，已运行的函数仍可能继续执行 | 使用后台工作线程，定向测试验证调用方释放 | Python 无法强制终止任意运行中的线程 | 有副作用的工具自行处理取消和重试幂等性 |
